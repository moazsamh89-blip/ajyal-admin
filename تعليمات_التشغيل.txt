==============================================
لوحة تحكم منصة أجيال الإيمان — Ajyal Admin Panel
==============================================

محتويات الحزمة:
- src/: الكود المصدري الكامل للوحة التحكم (React 18 + TypeScript + Vite + TailwindCSS + Lucide)
- public/: الأصول والشعار الرسمي الجديد (logo.png)
- dist/: النسخة المجمعة الجاهزة للرفع المباشر والإنتاج (Production Build)
- package.json & package-lock.json: تعريف الحزم والاعتماديات
- vite.config.ts, tsconfig.json: إعدادات البناء والتطوير
- run-admin.bat: ملف تشغيل سريع

طريقة التشغيل للتطوير:
1. تأكد من تثبيت Node.js
2. افتح المجلد في سطر الأوامر ونفذ:
   npm install
3. لتشغيل السيرفر المحلي:
   npm run dev
4. المتصفح: http://localhost:5173/

لرفع النسخة مباشرة للإنتاج (Production):
- مجلد dist يحتوي على النسخة الجاهزة الكاملة بعد عمل npm run build.
